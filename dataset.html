Each pixel represents an approximately 1 m × 1 m cell and encodes its average measured RSRP, clipped to [−144, −40] dBm. For nonzero grayscale values v, RSRP (dBm) = −144 + 104 × v / 255; zero is treated as empty.

The archives contain only the original grayscale scene PNGs. The corpus is released under CC BY 4.0.

Please cite GenRF when using the dataset.
