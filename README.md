# GenRF

Project website and data release for GenRF.

The dataset contains 121,363 measured radio-field scenes and is released under CC BY 4.0. Download the archives from the Dataset page.

The repository contains the static website and dataset documentation.

The website template is adapted from Nerfies under CC BY-SA 4.0. See THIRD-PARTY-NOTICES.md and WEBSITE-LICENSE.md.
